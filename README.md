每个分 P 文件名保留原投稿页码、分 P 名称和 CID。原始 XML 中每条弹幕时间是**该分 P 内的相对秒数**，PB 中 `progress` 为毫秒。XML `p` 属性的第 8 项是弹幕 ID，第 9 项在部分文件中为权重；不能把最后一项一律当作弹幕 ID。

`hacks-danmaku/merged/` 是保留不动的旧简单拼接；`calibration/<剧集>/aligned.xml` 是该集当前处理版，可能是画面候选或估算试播，文件名中的 `aligned` 不代表已通过实播确认。以同目录 `alignment.json` 的 `status`、证据及限制为准。

原始分 P 沿用已入库文件，通过相对路径、CID和SHA256关联到校对记录，避免重复保存多套无法分辨的原始数据。原视频、设备信息、个人目录和本地采集结果不在上述目录中。

## 已经做过的处理

1. **找回 CID 并逐包归档。** 每个分 P 按 6 分钟分包下载；保存原始 protobuf 和可读取的 XML，按弹幕 ID 去重，保留文本、时间、模式、字号、颜色、发送时间等可用字段。
2. **处理旧接口关闭提示和风控。** 旧 XML 接口返回“本视频弹幕功能已被关闭”，不是有效弹幕；此前 215 个分 P 的旧分段请求返回 JSON `-352`。补抓改用新版 WBI 接口、正常匿名会话、完整 UA/Referer、约每 2 秒一次的串行请求和连续失败停止策略，215 个分 P 均成功恢复。未使用账号 Cookie，未将 JSON 错误响应当作 `.pb` 弹幕。
3. **保留完整性依据。** 下载阶段逐条对照 PB 与 XML 的文本、时间和 ID，验证 291 个分 P、369 个分包、29,782 条弹幕；另验证归档 ZIP 的 CRC 和清单路径。
4. **排除数字名占位 P 后临时合并。** `merged/` 只处理与该集匹配的 `SxxExx-*` 切片；不把名称为 `0`、`1` 或其他非标准长 P 串入正片。它们的原始文件仍独立保留，未删除弹幕。
5. **修正过一次约 40 分钟的偏移。** 更早版本曾把数字名占位 P 的 2417 秒计入整集时间轴；更新版已排除。基线提交使用的是这一更新版。

## 时间轴处理方法与尚未完成的核对

### 相邻 P 的重叠

用户确认相邻 P 存在数秒重叠；举例中的秒数不是实际测量值。保留在 `hacks-danmaku/merged/` 和 `naive-merged.xml` 的旧合并算法为：

```text
临时整集时间 = 分 P 内弹幕时间 + 前面所有同集命名切片的存档时长之和
```

旧算法越往后越可能因未扣除重叠而偏移。当前 `calibration/` 将方法分开记录：第一、三集保留逐帧画面对照得到的映射候选；无独立画面的集数，按用户在2026-10-29明确指定的规则，将 `D=切片时长和−原片时长` 的正值均分到 `n−1` 个接点。第i个P起点为 `前面P的时长和−(i−1)×max(D,0)/(n−1)`。

均摊是**估算试播**，不是重叠实测；D为负时保留简单拼接、单独标记缺口，不做负重叠或拉伸。分P片长优先用存档整数时长；最后一条弹幕只作为片长下界，不代替视频结束时间。

精确校准需获取目标原片的实际媒体时长，并为每个分 P 找到可比对的音频、画面或字幕锚点，确定其在原片中的起止位置。若分 P 内也发生剪辑，需建立多段映射，而不是只给整个 P 一个偏移值。

当前已留档第一、三集的公开首帧及匹配测量，其余集的证据覆盖另见来源调查；原视频和原片提取图不入库。**单集总时长只能提供差值，不能唯一确定每个接点的重叠量或删减位置。** 状态明确区分用户实播通过、画面候选、均摊估算和缺口未解决。

## 本地校验与状态生成

需要 Python 3.9+ 标准库，无额外依赖、无需联网：

```bash
python3 scripts/audit_archive.py
python3 scripts/build_calibrated_episode.py S01E01 --check
python3 scripts/compare_part_intervals.py
python3 scripts/audit_first_frame_sources.py
git diff --check
```

脚本校验清单路径、XML 条数、弹幕 ID、原始分包与 XML 的文本/时间一致性，并更新 `docs/时间轴状态.md`、`processing/timeline-status.json`。它不会修改原始弹幕，也不会凭空校准时间轴。

`docs/时间轴状态.md` 与 `processing/timeline-status.json` 侧重原始存档的基础审计；处理进度及播放版以 `calibration/` 为准。重建ASS需Python 3.11+和[固定版本依赖](requirements-calibration.txt)，命令及估算算法见[逐集留档说明](calibration/README.md)。

后续每次完成变动必须提交。提交使用 Conventional Commits，例如 `fix(timeline): 校准第一集相邻切片重叠`；正文按需用中文记录依据、影响和验证。
