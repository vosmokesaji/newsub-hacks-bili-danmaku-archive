## P1 不能直接用零秒

参考图已有亮NEW标识与顶端版权说明；原片零秒缺少这些特征。逐帧联合比较黑场、标识和顶端文字后，兼容区间为 **4.004000–4.963292秒**，共24帧。原片约1–4秒的max ORIGINAL片头与参考图不同。

静态黑场无法唯一定位；最低像素误差所在的4.671333秒只是压缩噪声导致的伪唯一，未将它作为精确起点。试播选取兼容区间最早的 **4.004秒** 作为P1偏移，属于有依据但不唯一的试播选择。该选择与原P1仅297秒的元数据一起支持“可能裁去约4秒片头”的解释，尚未证明实际裁切时间。
