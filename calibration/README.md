## 留档内容

每集的 `alignment.json` 保存原始分P相对路径、CID、SHA256、条数，及合并/校对后XML和ASS的校验值。原始XML/PB沿用 `hacks-danmaku/<剧集>/`；`naive-merged.xml` 保留当时未经重叠处理的简单合并版本。所有处理另存，不覆盖原始弹幕。

参考版本只保存发行文件名、时长和校验值，以辨别相同名称但内容不同的视频。ASS文件名与对应视频的主文件名完全一致，仅扩展名改为 `.ass`；本地播放时放在视频旁，便于播放器自动加载。

## 第一集的证据与限制

P2–P6 的公开首帧均在参考原片中找到高度相似的帧，使用真实PTS定位，候选画面间隔都是297.005041667秒。每个匹配分数、PTS、参考图片来源URL和校验值均留档。

用户在2026-10-29实播确认“弹幕的时间点没问题，非常完美”。确认对应的ASS校验值为 `94cebd8db5e2b99254831da8f6ad9169fdbde121763b871dcfe1364fb8c8187e`。

这确认的是观看效果；尚未取得原分P的精确媒体时长，也未证明首帧图片在分P内的采样偏移为零。不能把整数301秒减去候选间隔直接当作实测重叠时长，也不据第一集规律推定所有剧集。

## 重现与检查

`python3 scripts/build_calibrated_episode.py S01E01 --check` 无需联网和额外依赖，核对原始文件、映射重建XML、产物和公开图片校验值。

重建ASS需要本目录要求的 `biliass==2.5.0`：在项目虚拟环境安装 `requirements-calibration.txt` 后执行 `python3 scripts/build_calibrated_episode.py S01E01`。会重新生成本集处理产物并更新校验值，不修改原始分P。

状态必须区分：用户实播确认、独立画面对照得到的候选对齐、仅时长比较、证据不足。无独立锚点时不凭空填入起点、重叠或删减位置。
