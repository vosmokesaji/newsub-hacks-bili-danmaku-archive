## 留档内容与时间轴规则

原始XML/PB沿用 `hacks-danmaku/<剧集>/`。清单关联原始CID、XML路径、SHA256及条数；新登记集同时逐包记录PB校验值。命名为0/1等不匹配剧集切片的P单列 `excluded_parts`，不加入正片累计时间；其原始数据与弹幕保留。非标准长P待辨认集则保留全部原始引用，暂不合并。

`naive-merged.xml` 保存未经重叠处理的旧合并。`aligned.xml` 与同名ASS按该集清单状态理解：文件名中的aligned不代表已验证。原视频只记录发行文件名、时长、帧率、字节数和SHA256，以识别相同名称但内容不同的版本。

无旧CID独立锚点的命名切片，按用户在2026-10-29指定规则试播：D=切片时长和−原片时长，o=max(D,0)/(n−1)，第i个P起点=前面片长和−(i−1)×o。D为负时保留简单拼接并标记缺口，不做负重叠或拉伸。最后一条弹幕只作为时长下界，不替代视频时长。

S01E05、S01E08、S03E02、S05E03存在未解决的时长缺口。S03E02/S03E03/S05E03/S05E07的名称有【删】线索，具体区间仍未测定；总和较长也不能证明没有删减。S05E08、E09只有异常长P，未生成播放版，不能按长P时长压缩。

## 重现与检查

Python 3.9+标准库可执行 `python3 scripts/build_calibrated_episode.py <剧集> --check`，核对原始引用、旧合并和已生成XML/ASS。非标准长P只校验原始数据，保持映射待处理。

新集可用 `scripts/register_calibration.py` 登记不含路径的发行标识和媒体测量；参数见 `--help`。拒绝覆盖已有校对记录，命名切片与排除P必须覆盖原目录。

重建ASS需要Python 3.11+及[固定依赖](../requirements-calibration.txt)。执行 `python3 scripts/estimate_equal_overlap.py <剧集>` 重建估算/缺口试播，不覆盖画面对齐或非标准待处理集；`--playback-dir <已有本地目录>` 同步同名ASS，路径不写入清单。指定 `python3 scripts/build_calibrated_episode.py <剧集>` 可按已有映射重建。

`python3 scripts/compare_part_intervals.py`、`python3 scripts/update_calibration_index.py` 重建接点对照与本索引；`python3 scripts/audit_first_frame_sources.py` 验证公开图片与来源。不读取原片，不联网。
